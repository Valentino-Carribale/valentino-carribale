# 🎮 Gaming Trade

**Gaming Trade** es un álbum de figuritas digital, destinado a registrar videojuegos de los usuarios, ordenados en rarezas por su popularidad.

Cada figurita representa un videojuego e incluye la información más relevante:
* Portada
* Plataforma y Numeración
* Gameplay de YouTube (link externo)
* Desarrollador
* Fecha de lanzamiento
* Género
* Mapa/Entorno
* Modo de Juego
* Rareza

---

## 📖 Descripción

El proyecto fue desarrollado utilizando únicamente **HTML5** y **CSS3**, sin frameworks externos o funcionalidades de JavaScript, y con esto integrar conocimientos:

* HTML
    - HTML semántico
    - Estructura correcta del documento
    - Organización del contenido
    - Navegación entre páginas

* CSS
    - Box Model
    - Flexbox
    - Position
    - Responsive básico
    - Hover y efectos visuales
    - Jerarquía visual
    - Diseño consistente

* Organización del Proyecto
    - Carpetas ordenadas
    - Rutas correctas
    - Recursos multimedia locales
    - Claridad estructural

## ✨ Características

* 💻 Categorías separadas por plataforma:

  - PC
  - Consola
  - Celular

* 🏆 Página **TOP 3** con los videojuegos más populares de las 3 categorías.
* 🌈 Rarezas por colores (Común, Poco Común, Raro, Épico, Legendario y MÍTICO. *Referencias en pie de página/documentación*).
* 🎵 Música Tech de fondo.
* 📺 Enlaces a los gameplays en cada juego.
* 📊 Barra de progreso con el porcentaje de cada categoríad del álbum.
